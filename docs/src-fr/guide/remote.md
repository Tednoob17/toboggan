# Présenter depuis n'importe quel appareil

Toboggan découple le serveur (qui fait tourner les slides) du client (qui les contrôle). Résultat : vous pouvez piloter votre présentation depuis un téléphone, une tablette ou un second PC.

## Configuration

1. Lancez le serveur sur le PC branché au projecteur.
2. Ouvrez `http://<adresse-du-serveur>:<port>` sur votre téléphone/tablette.
3. Utilisez les flèches pour naviguer.

## En pratique

- Les deux appareils doivent être sur le même réseau (ou le serveur doit être accessible).
- Le client Web est léger — pas d'installation, juste un navigateur.
- Plusieurs clients peuvent se connecter simultanément : chaque appareil affiche et contrôle les slides.
