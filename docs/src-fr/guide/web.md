# Client Web

Le client Web est fourni par le serveur. Ouvrez simplement `http://<adresse>:<port>` dans un navigateur.

## Fonctionnalités

- Affichage des slides en temps réel
- Navigation (flèches gauche/droite)
- Numéro de slide
- Synchronisation entre tous les clients connectés

## Utilisation à distance

Le client Web permet de contrôler la présentation depuis un téléphone ou une tablette pendant que le serveur tourne sur le PC du projecteur.

Voir [Présenter depuis n'importe quel appareil](remote.md) pour les détails.
