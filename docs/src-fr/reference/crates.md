# Référence des crates

Toboggan est organisé en plusieurs crates Rust :

| Crate | Rôle |
|---|---|
| `toboggan-core` | Types et logique partagés |
| `toboggan-server` | Serveur WebSocket + serveur HTTP |
| `toboggan-cli` | Convertisseur Markdown → TOML |
| `toboggan-tui` | Client terminal |
| `toboggan-web` | Interface Web (TypeScript/React) |
